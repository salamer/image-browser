# Mac 实机验证清单（M5，Apple Silicon）

## 首次启动
- [ ] 运行 `xcodebuild -project SwiftLens.xcodeproj -scheme SwiftLens -destination 'platform=macOS,arch=arm64' CODE_SIGNING_ALLOWED=NO build`
- [ ] 使用空的 `Pictures` 文件夹首次启动，出现「欢迎使用」、主按钮与键鼠速查；点击 `⌘O` 可加载新目录
- [ ] 有图目录启动直接显示图片，无欢迎遮挡；无搜索结果时出现「清除筛选」
- [ ] 空文件夹与没有可识别格式的文件夹都不会卡住或出现无限滚动空间

## 浏览/鼠标
- [ ] 1k / 10k JPG+PNG+WebP 混合目录首屏连续填充，长列表滚动没有大量空白 tail
- [ ] 拖动主窗口宽度/侧栏分隔线，网格列数重排；切目录后再切回恢复滚动位置
- [ ] `⌘` 多选、`⇧` 范围选中、`⌘A` 全选；`⌘C` / `⌘V` 复制多个文件到新目录
- [ ] 右键提供 Finder 定位、路径复制、改名、复制、移动和移到废纸篓（最后一项需要确认）
- [ ] 在搜索输入时 `⌘A/⌘C/⌘V` 操作文本而非图片，`Esc` 不会导致意外文件操作
- [ ] 用 `⌘[/⌘]` 后退前进、`⌘↑` 到上级、`⌘B` 折叠侧栏、`⇧⌘N` 新建文件夹

## 大图预览
- [ ] 不同比例的横图、竖图、方图首次进入预览时居中、Fit 到窗口，并且不需要拖动 zoom 滑块
- [ ] 连续改变窗口尺寸（包括最小尺寸和全屏）仍然正确 Fit
- [ ] 双击图片或 `Z` 转 100% 后缩放/拖动，`⌘0` 恢复 Fit
- [ ] 鼠标进入详情页底部约 150pt，胶片栏弹出；点击相邻图、滚轮横向滚动、`T` 固定
- [ ] 快速按方向键连续翻页 50 次，没有旧图异步回调覆盖当前图
- [ ] 滚动视图没有异常大 blank tail / 不会有新 Auto Layout constraint warnings

## 文件变更与缓存
- [ ] 同路径图片替换成另一张、mtime/size 变化后应显示新内容
- [ ] 重命名、复制、移动后评分和收藏在应用内正确迁移/复制
- [ ] 非法文件名、目标已存在、权限不足、只读目录报错而不崩溃
- [ ] 复制 1GB 大文件时 UI 仍可滚动；切目录不触发过时刷新
- [ ] 观察 ~/Library/Caches/SwiftLens/Thumbnails-v3 的大小和 prune 行为

## 专业性能基准
- [ ] Release + Time Profiler：扫描函数/图片解码没有连续阻塞主线程
- [ ] Scroll（热缓存）录制 p95 FPS 与 main-thread frame time
- [ ] 1000 / 10000 / 50000 文件分别统计首次可交互、首屏、热缓存、峰值 RSS
- [ ] 在你的 M5 上与同目录 MediaOne/Finder/FlowVision 进行数据而非主观描述的对比

未进行以上实机检查前不能宣称已超过 MediaOne、完成完整功能对齐或达到任何性能数值。
