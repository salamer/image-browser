# macOS/M5 实机验收清单

1. `bash Scripts/verify_macos_build.sh` 必须出现 `PASS full macOS arm64 AppKit build`；若报错附完整 Xcode 首个 error。
2. 启动：无旧目录时显示空状态引导，`⌘O` 打开；顶部无第二行工具条；标题栏红黄绿按钮与右边控件不重叠。
3. 侧栏：点左上 sidebar icon 和 `⌘B`，折叠后图片区域宽度真实增加；展开恢复目录树宽度；拖分割线并重启，宽度仍在合理范围内。
4. 键盘：网格空格/回车进入预览，左右键/J/K 翻页，Esc 返回；搜索框聚焦时箭头移动光标；目录树聚焦时左右展开/折叠。
5. Resize：竖图/横图正方图连续变更窗口宽高和侧栏宽度；Fit 始终完整居中；手动 100% 放大不突然重置；窄窗工具栏不出现约束冲突。
6. 预览：Tab 专注模式，边缘显示自然，胶片栏靠近底边自动显示，T 固定后可鼠标横向滚动；图片切换不显示上一张的迟到低清图。
7. hover：顶部每个 icon 有 Tooltip 及轻微背景变化；缩略图有悬浮阴影，右键文件操作可用。
8. 目录：空目录欢迎页、搜索无结果、递归开关、排序、星级过滤、多选、复制粘贴及移到废纸篓。
9. 资源：Dock 与 App Switcher 应显示蓝青色 SwiftLens AppIcon，不是默认 Swift 可执行程序图标。
10. Instruments：首次打开 1k/10k 图片分别测首屏时间、Peak RSS、滚动掉帧和连续翻页延迟；与 MediaOne 比较前必须统一同一目录、缓存冷热状态和分辨率。
